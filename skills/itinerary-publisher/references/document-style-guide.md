# Itinerary document style guide

The document should optimize for scanning while traveling, not resemble a glossy brochure.

## Page and table

- US Letter, portrait
- 0.5-inch margins
- One full-width, three-column table
- Approximate column proportions: 22.5% transportation / 51.7% plans / 25.8% lodging
- Thin dark-gray cell borders
- Compact cell padding and Calibri 10-point body text
- Prevent individual day rows from splitting across pages when practical

## Date bands

- One merged row spanning all three columns before each day
- Centered date text
- Pale blue fill (#E0ECF8)
- Slightly smaller than body text

## Transportation column

- Carrier/flight/train identifier bold
- Route and times on following lines
- Soft pastel fill chosen consistently from a restrained palette

## Plans column

- Normal travel notes remain white
- Booked excursions/activities use pale yellow (#FFFFE0)
- Activity title bold; confirmation/details below it

## Lodging column

- First/full property details use pale green (#E0FFE0)
- Property name bold
- Address and confirmation number below it
- On subsequent days at the same property, showing just the property name without green fill is acceptable

## General

- Preserve practical wording and confirmation data verbatim
- Do not include prices, fares, room rates, taxes, fees, totals, amounts paid, balances, or other currency amounts
- Avoid marketing copy, cancellation-policy boilerplate, icons, photographs, gradients, oversized headings, or decorative clutter
- Favor compact vertical spacing so a multi-week trip remains only a few pages
- Include "empty" days for which there are no known events between the start date and end date
